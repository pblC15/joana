# Bella Studio · Joana Costa Lash Academy

Landing page da Joana Costa, Formadora & Lash Designer em São João da Madeira.

## Antes de publicar
- **Número de WhatsApp:** abra `script.js` e troque `351900000000` pelo número real (indicativo 351, sem + nem espaços). Todos os botões de WhatsApp, incluindo a "Marcação em três toques", passam a usá-lo.
- **Serviços e textos da formação:** em `index.html`, procure ✏️.

## Publicar no GitHub Pages
1. Crie um repositório novo no GitHub (ex.: `joanacosta-lash`).
2. Envie todos os ficheiros desta pasta, incluindo `assets/` e `.nojekyll`.
3. Em **Settings → Pages**, escolha *Deploy from a branch*, branch `main`, pasta `/ (root)` e clique **Save**.
4. Em 1–2 minutos o site fica em `https://SEU-UTILIZADOR.github.io/joanacosta-lash/`.

## Estrutura
```
index.html   página
style.css    estilos
script.js    WhatsApp, marcação em três toques e cópia do código de desconto
assets/      logótipo (fundo transparente), monograma JC e imagem de partilha
.nojekyll    evita processamento Jekyll
```
